# 🚀 Cache Clearing Guide - SME CrowdFund VN

## 🔄 Browser Cache Issues Fix

### ⚡ **Force Refresh Methods:**

#### **Chrome/Edge:**
```
Ctrl + Shift + R  (Hard refresh)
Ctrl + F5         (Reload ignoring cache)
F12 → Network → Disable cache ✓ → Reload
```

#### **Firefox:**
```
Ctrl + F5         (Hard refresh)
Ctrl + Shift + R  (Force reload)
```

#### **Safari:**
```
Cmd + Shift + R   (Hard refresh)
Cmd + Option + R  (Empty cache and reload)
```

### 🧹 **Manual Cache Clear:**

#### **Chrome:**
1. F12 → Application tab
2. Storage → Clear storage
3. Click "Clear site data"

#### **Firefox:**
1. F12 → Storage tab  
2. Right-click → "Delete All"

### 🌐 **Alternative Testing:**

#### **Incognito/Private Mode:**
```
Ctrl + Shift + N  (Chrome)
Ctrl + Shift + P  (Firefox)
```

#### **Different Browser:**
- Test in Edge if using Chrome
- Test in Firefox if using Edge

### 📱 **Mobile Testing:**
- Pull down to refresh
- Clear browser data
- Try different mobile browser

### 🔍 **Developer Tools Check:**
1. F12 → Console tab
2. Look for image loading errors
3. Network tab → Check image requests
