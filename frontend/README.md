# SME Crowdfund VN Frontend

This is the frontend application for the SME Crowdfund VN project, a crowdfunding platform designed specifically for small and medium enterprises (SMEs) in Vietnam. The application is built using Next.js and Tailwind CSS, providing a modern and responsive user experience.

## Features

- **Responsive Design**: The application is fully responsive, ensuring a seamless experience across devices.
- **User Authentication**: Users can register, log in, and manage their profiles.
- **Campaign Management**: SMEs can create and manage crowdfunding campaigns.
- **Investment Dashboard**: Investors can view their profiles, investment portfolios, and performance metrics.
- **Campaign Discovery**: Users can browse and filter campaigns based on various criteria.

## Getting Started

To get started with the frontend application, follow these steps:

1. **Clone the repository**:
   ```
   git clone https://github.com/yourusername/sme-crowdfund-vn.git
   cd sme-crowdfund-vn/frontend
   ```

2. **Install dependencies**:
   ```
   npm install
   ```

3. **Run the development server**:
   ```
   npm run dev
   ```

4. **Open your browser**:
   Navigate to `http://localhost:3000` to view the application.

## Folder Structure

- `src/pages`: Contains the application pages.
- `src/components`: Contains reusable UI components.
- `src/styles`: Contains global styles.
- `src/hooks`: Contains custom hooks for state management and responsiveness.
- `src/contexts`: Contains context providers for global state management.
- `src/services`: Contains API client and payment processing services.
- `src/lib`: Contains utility functions for internationalization.
- `src/types`: Contains TypeScript types and interfaces.
- `src/utils`: Contains utility functions for form validation.
- `src/__tests__`: Contains tests for components.

## Technologies Used

- **Next.js**: A React framework for server-side rendering and static site generation.
- **Tailwind CSS**: A utility-first CSS framework for styling.
- **TypeScript**: A superset of JavaScript that adds static types.
